# 🚀 API Studio – Gemini AI Chat

A simple AI chatbot built using **HTML, CSS, JavaScript and Google Gemini API**.

API Studio allows users to interact with Google's Gemini AI through a simple web-based chat interface.

## ✨ Features

- Simple and clean user interface
- Real-time AI responses using Gemini API
- User and AI messages displayed separately
- Error handling
- Scrollable chat window
- Lightweight and beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Gemini API

```text
API-Studio/

```

## ⚙️ Installation & Setup

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Get your Gemini API key from Google AI Studio.
4. Open `script.js`.
5. Add your API key:

```javascript
const API_KEY = "YOUR_GEMINI_API_KEY";
```

6. Save all files.
7. Open `index.html` using VS Code Live Server.

## 🔑 API Configuration

This project uses the Google Gemini API with the `gemini-2.5-flash` model.

Get your API key:

https://aistudio.google.com/app/apikey

**Security Note:** Never upload your real API key to a public GitHub repository. For production use, keep the API key on a secure backend server.

## 🎯 Project Purpose

This project was created to practice frontend web development and learn how to integrate AI APIs into a web application.
